# 💪 FitLog

A modern, responsive workout library and daily workout planner built with Next.js.

## 🔗 Links

- Live Link: Add your deployed Vercel/Netlify URL here
- GitHub: <https://github.com/soheldevbd>

## ✨ Key Features

- Workout library powered by a REST API
- Responsive 3-column desktop workout grid
- Dynamic workout details pages
- Add workouts to Today's Plan with a 5-lift cap
- Save workouts for later
- localStorage persistence across reloads
- Mark workouts as Done or remove them
- Live navbar counters and plan metrics
- Sort workouts by Duration, Calories, or Rating
- Toast notifications for user actions
- Loading and custom 404 states

## 🛠️ Technologies

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Lucide React
- Sonner
- REST API
- localStorage
